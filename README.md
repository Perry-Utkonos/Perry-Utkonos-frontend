# Fate

Демо приложения знакомств: анкеты, свайпы, лайки, чаты и совместимость. Есть свой профиль, настройки и две темы. Интерфейс работает на телефоне и компьютере.

React 18 · TypeScript · Vite · React Router · Lucide · CSS

## Запуск

Нужны Node.js и npm. Проверено на Node.js 24.

Склонируйте репозиторий или скачайте и распакуйте ZIP. Откройте терминал в папке с `package.json`:

```sh
npm ci
npm run dev
```

Браузер откроется автоматически. Обычно адрес — `http://127.0.0.1:5173`; если порт занят, используйте адрес из терминала. Изменения в коде сразу видны на странице. Остановить сервер — `Ctrl+C`.

В PowerShell при ошибке выполнения `npm.ps1` используйте `npm.cmd` вместо `npm`.

| Команда | Для чего |
| --- | --- |
| `npm ci` | Установить зависимости. |
| `npm run dev` | Запустить приложение локально. |
| `npm run build` | Проверить типы и собрать сайт в `dist/`. |
| `npm run preview` | Посмотреть готовую сборку; сначала выполните `build`. |

## Структура

```text
src/
├── components/   # Карточка, навигация, окно совпадения и другие элементы
├── pages/        # Экраны приложения
├── layouts/      # Общий макет
├── hooks/        # Состояние чатов, лайков и темы
├── data/         # Анкеты, переписки и работа с сообщениями
├── types/        # Типы данных
└── styles/       # Общие стили, темы и порядок подключения CSS
public/images/   # Фото и изображения оформления
design/          # Материалы дизайна и скрипты для Figma
tests/           # Автоматические проверки кода
```

### Основной код

| Файл | За что отвечает |
| --- | --- |
| `src/main.tsx` | Запускает React, подключает роутер и стили. |
| `src/App.tsx` | Собирает состояние приложения и передаёт его страницам. |
| `src/AppRoutes.tsx` | Адреса страниц и переходы из анкеты. |
| `src/layouts/AppLayout.tsx` | Общий макет, навигация и окно совпадения. |
| `src/routeLoaders.ts` | Загружает страницы по мере необходимости. |
| `src/hooks/useChats.ts` | Сообщения и актуальный список чатов. |
| `src/hooks/useLikes.ts` | Открытие и закрытие совпадения после лайка. |
| `src/hooks/useTheme.ts` | Применение и сохранение темы. |
| `src/theme.ts` | Две темы и чтение сохранённого выбора. |
| `src/data/users.ts` | Свой профиль `me` и анкеты `users`. |
| `src/data/chats.ts` | Начальные сообщения и превью чатов. |
| `src/data/chatState.ts` | Добавление сообщений и обновление превью. |
| `src/types/index.ts` | Типы анкеты, сообщения и превью чата. |

### Стили

`src/styles/global.css` — общие цвета, темы, кнопки и базовые стили. `responsive.css` — адаптация под размеры экрана; граница мобильного и десктопного макета — 760 px. `shared.theme.css` — оформление общих элементов под темы.

Стили экранов, компонентов и макета лежат рядом с ними: `.css` — основные правила, `.theme.css` — оформление под темы. Все файлы подключаются через `src/styles/index.ts` в порядке «основные стили → адаптивность → темы». При добавлении CSS сохраняйте этот порядок.

### В корне

- `index.html` — заголовок вкладки, описание сайта, шрифты и вход в приложение.
- `package.json` — зависимости и команды; `package-lock.json` — их точные версии.
- `vite.config.ts` — настройки сборки и React-плагина.
- `tsconfig.json` — общая конфигурация TypeScript; `tsconfig.app.json` — для `src/`, `tsconfig.node.json` — для конфигурации Vite.
- `.gitignore` — исключает `node_modules/`, `dist/`, временные скриншоты и локальные файлы. `package-lock.json` должен быть в Git.

`node_modules/` создаётся при установке зависимостей, `dist/` — при сборке. Исходники меняются в `src/` и `public/`.

## Экраны

Все страницы находятся в `src/pages/`.

| Файл | Адрес | Экран |
| --- | --- | --- |
| `FeedPage.tsx` | `/` | Лента анкет. |
| `UserProfilePage.tsx` | `/profile/:id` | Чужой профиль и фотографии. |
| `ChatsPage.tsx` | `/chats` | Список чатов. |
| `ChatPage.tsx` | `/chat/:id` | Переписка. |
| `CompatibilityPage.tsx` | `/compatibility/:id` | Совместимость пары. |
| `ProfilePage.tsx` | `/me` | Свой профиль. |
| `SettingsPage.tsx` | `/settings` | Тема и настройки. |
| `SubscriptionPage.tsx` | `/subscription` | Демо подписки. |

`:id` — идентификатор анкеты: `mila`, `leo`, `anya` или `sasha`. Например, `/profile/mila`. Неизвестный адрес ведёт на `/`.

В `src/components/`:

- `ProfileCard.tsx` — карточка анкеты и свайпы.
- `BottomNav.tsx` — нижнее меню.
- `MatchModal.tsx` — окно совпадения после лайка.
- `CompatibilityBadge.tsx` — процент совместимости.
- `ThemePicker.tsx` — выбор темы.
- `CentaurIcon.tsx` — фирменная иконка.

Для нового экрана создайте файл в `src/pages/` и добавьте маршрут в `AppRoutes.tsx`. Если нужна загрузка по требованию, добавьте функцию в `routeLoaders.ts`.

## Данные

Анкеты меняются в `src/data/users.ts`, начальные переписки — в `src/data/chats.ts`.

Для новой анкеты добавьте объект в `users` с уникальным `id`, а фотографии положите в `public/images/`. Если нужен начальный чат, добавьте запись с тем же `userId` в `chatPreviews` и сообщения под этим ключом в `initialMessages`.

Путь к фотографии в данных указывается как `/images/имя-файла.jpg`.

## Figma

В `design/` лежат материалы макетов и скрипты для создания экранов в Figma. Работа с ними описана в [design/README.md](design/README.md), замечания к макетам — в [UI-UX-handoff.md](design/UI-UX-handoff.md).

Макет и сайт могут отличаться; их визуальное совпадение пока не проверено.

## Ограничения демо

Сейчас готов интерфейс с демонстрационными данными. Серверная часть будет подключена позже.

- Авторизации, базы данных и обмена сообщениями между пользователями нет.
- Любой лайк показывает совпадение; ответный лайк не проверяется.
- Отправленные сообщения обновляют список чатов, но исчезают после перезагрузки. Счётчик непрочитанных при открытии чата не сбрасывается.
- Совместимость задана в анкетах, а не рассчитывается.
- Подписка и Premium — демонстрация интерфейса, без оплаты. Замена фото своего профиля не реализована.
- Тема и переключатели настроек сохраняются в браузере. Реальными уведомлениями и приватностью они не управляют.

## Размещение

`npm run build` создаёт готовый сайт в `dist/`. На хостинге настройте возврат `index.html` для адресов приложения, например `/chat/mila`, иначе обновление такой страницы может дать 404.

Для размещения сайта в подпапке, в том числе на GitHub Pages по адресу `/имя-репозитория/`, нужно согласовать `base` в Vite, `basename` роутера и пути к изображениям. Текущая конфигурация рассчитана на корень домена.
